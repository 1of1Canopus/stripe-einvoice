# stripe-einvoice

Legal EN 16931 e-invoices from Stripe Billing, for Spring Boot applications.

This repository is under construction. Nothing here is released yet.

- Free core: XRechnung and Peppol UBL documents, the official validator suites, a per-seller
  legal numbering series in which every allocated number has a recorded, chained disposition,
  Stripe webhook intake, an archive with a tamper-evident issuance log, the reconciliation
  sweep and the health signal.
- Licence: FSL-1.1-ALv2 (see `LICENSE` and `NOTICE`). Converts to Apache-2.0 two years after
  each version is published.
- Security policy: `SECURITY.md`.
